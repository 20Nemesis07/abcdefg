OIL HSSE SIF-Precursor AI Prototype

Prototype objective: automatically flag SIF potential, map reports to IOGP Life-Saving Rules, and surface recurring precursor patterns for targeted interventions.

Implementation Roadmap

Phase What to Build Deliverable Success Metric
1. Data foundation (Week 1) Collect UA/UC, near-miss, incident text; standardize fields (site, activity, location, barrier failure). Clean training dataset and data dictionary. >95% reports parsable with mandatory fields.
2. SIF classifier baseline (Week 2) Rule/keyword baseline and annotation guidelines for SIF vs non-SIF labels. Baseline model API + confidence score. Recall focus: SIF recall >85% on validation set.
3. Life-Saving Rule mapper (Week 3) Multi-label text classification to Energy Isolation, Hot Work, Confined Space, Line of Fire, etc. LSR auto-tag service with top-2 tags. Macro-F1 >75% on labeled set.
4. Precursor pattern mining (Week 4) Extract activity-location-barrier patterns and frequency trends. Ranked precursor clusters and heatmaps. Top clusters explain >60% SIF-potential reports.
5. Dashboard + workflow (Week 5) Role-based dashboard ranking sites and activities by SIF precursor density. Interactive dashboard with filters and drill-down. HSE users can identify top-5 intervention targets in <2 minutes.
6. Pilot + improvement (Week 6+) Human-in-the-loop review, model retraining, threshold tuning, governance. Pilot report and go-live plan. Reduction in missed high-potential events month-on-month.
