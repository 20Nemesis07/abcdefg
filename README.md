# abcdefg

Prototype roadmap and interactive demo for OIL HSSE SIF-precursor triage.

## What this includes
- 6-phase implementation roadmap for the Smart India Hackathon problem statement.
- Browser-based prototype that:
  - classifies reports as SIF-potential vs non-SIF,
  - maps reports to IOGP Life-Saving Rules,
  - ranks recurring precursor patterns and SIF density.
